# 基于《马克思恩格斯选集（第二版）》的 TeX 写作模版

## 命令

### 章节级别

```tex
\cover{path to cover}       -> 封面

\tintro{title}              -> 前言     (可选)

\tyear{title}               -> 年份标题 (可选)

\tdoc{title}                -> 文献标题

\tpart{title}               -> 篇       (可选)

\tchapter{title}            -> 章
\tchapternonum{title}       -> 无编号章

\tsection{title}            -> 节       1.
\tsectionnonum{title}       -> 无编号节 1.

\tsubsection{title}         -> 子节       A.
\tsubsectionnonum{title}    -> 无编号子节 A.

\tsubsubsection{title}      -> 小节       (1)
\tsubsubsectionnonum{title} -> 无编号小节 (1)
```

### 注释级别

```tex
\nauthor{comment} -> 作者添加的注释
\neditor{comment} -> 编辑 / 译者添加的注释
\nend{comment}    -> 尾注
```
